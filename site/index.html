MtpMount

Mount Android phones, GPS units, cameras and other USB devices as a browsable macOS volume, right in Finder.

Download the latest release View on GitHub

What it is

MtpMount mounts any device that exposes its storage over MTP over USB (Android phones, GPS units, cameras, music players, e-readers) as a volume you can browse in Finder, using Apple's File Provider API. No kernel extension, no reboot. The device appears in Finder's sidebar under Locations and under ~/Library/CloudStorage/, and works from the Terminal (ls, cp, rsync).

Device I/O is a self-contained PTP/MTP implementation over Apple's IOUSBHost framework, with no libmtp and no third-party dependencies.

Native Finder volume

Copy, rename, move, create and delete files and folders like any other disk.

Plug and go

Devices appear when connected and their location is removed when you unplug them.

Live changes

A new photo taken while connected shows up in Finder within a few seconds.

No dependencies

Pure Apple frameworks. Developer ID signed and notarized.

Requirements

An Apple Silicon Mac on the latest macOS. That's it. Nothing else to install.

Installation

  1. Download & install the app

    Grab the latest MtpMount-x.y.z.dmg from the Releases page, open it, and drag MtpMount into Applications. It must run from Applications.

  2. Open MtpMount

    Launch it from Applications. On first run it installs a small background helper. MtpMount lives in the menu bar.

  3. Turn on the File Provider extension (the one manual step)

    macOS registers the extension disabled, so you have to enable it once by hand. MtpMount's window has a button that jumps you straight to the right settings pane.

    The toggle you have to flip yourself

    Open System Settings → General → Login Items & Extensions, find MtpMount under Extensions, click the ⓘ next to it, and switch on File Provider. On some macOS versions it sits under a File Providers category instead. Enable MtpMount there.

  4. Connect your device

    Use a USB data cable and unlock the device. On an Android phone, tap the USB notification and choose File transfer. The device appears under its own name (e.g. “Galaxy S25”) in MtpMount's window and in Finder's sidebar. “Show in Finder” opens it.

Why isn't that toggle automatic?

No, and that's intentional. macOS treats a File Provider extension as something the user must consent to, so there is no API for an app to enable its own extension on your behalf. An app that could silently switch on a Finder-integrating extension would defeat the consent model.

Apps delivered outside the Mac App Store (like this one, signed with a Developer ID and notarized) always register their extensions in a disabled, pending-approval state. MtpMount does everything it's allowed to: it registers the provider and the helper automatically, and its window deep-links you straight to the exact settings pane (via the private x-apple.systempreferences:...LoginItems-Settings.extension URL). The final flip of the switch is reserved for you, and you only have to do it once.

Using it

You can copy files off the device, copy files onto it, and create, rename, move and delete files and folders. A few things worth knowing:

  • Several devices at once: each gets its own location in Finder.
  • Cameras are left alone: a device whose storage is entirely a camera file system (DCF) is released right away, so Photos and Image Capture keep working.
  • Removed on unplug: a device's location disappears when you disconnect it and comes back when you reconnect.
  • No in-place edits: MTP has no partial writes, so to edit a file on the device, copy it to your Mac, edit it, and copy it back.

Troubleshooting

“Device is in use by another app”
macOS and other tools grab MTP devices. Quit Android File Transfer, OpenMTP and any maker's sync app. If Image Capture or Photos opens when you plug the device in, open Image Capture, select the device, and set “Connecting this device opens” to No application. Then unplug and reconnect.
“No device connected” although it's plugged in
Use a data cable (not charge-only), unlock the device, choose File transfer in the phone's USB notification, and try another port or cable.
The device doesn't appear in Finder
Make sure the extension is enabled (step 3), open MtpMount once with the device attached, then use Troubleshooting → Reset in the window if it's still missing.
“The MtpMount helper isn't running”
Use Troubleshooting → Reinstall helper.
Finder shows stale contents
Use Troubleshooting → Refresh Finder.

Uninstall

Open MtpMount, choose Troubleshooting → Uninstall…, then move MtpMount to the Trash. That removes the helper's LaunchAgent (~/Library/LaunchAgents/no.synth.mtpmount.helper.plist) and the Finder locations.
